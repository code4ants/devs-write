# devs-write
A collection of stories written by members of this org, published at https://devswrite.eapp.site.

- Each author has a folder under `_stories/`; each story is a subfolder with chapters.
- Each story picks one theme: `fantasy`, `sf` or `newspaper`.
- See [docs/AUTHORING.md](docs/AUTHORING.md) to add a story or chapter.
- Built with Jekyll and deployed by GitHub Actions (`.github/workflows/pages.yml`).
